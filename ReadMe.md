# 🎨 PORTFOLIO: MyStyle Web Publishing Project

> **"복잡함을 덜어내고, 직관적인 구조와 감각적인 비주얼로 최적의 인터페이스를 구축합니다."**
> AI Creative 기반의 UI/UX 디자인 감각과 HTML5/CSS3 퍼블리싱 기술을 결합하여 다양한 테마의 인터랙티브 웹 페이지를 구축한 프로젝트 저장소입니다.

---

## 🧑‍💻 About Me & Project Philosophy
* **사용자 중심 인터페이스**: 사용자가 정보를 탐색할 때 겪는 피로감을 최소화하고, 가장 직관적으로 콘텐츠에 몰입할 수 있는 구조를 고민합니다.
* **디자인과 퍼블리싱의 융합**: AI 디자인 툴(Midjourney, DALL·E 등)과 Figma를 활용하여 감각적인 비주얼 소스를 기획하고, 이를 시맨틱 마크업과 CSS Layout(Flexbox/Grid)을 통해 완벽한 웹 화면으로 구현해냅니다.

---

## 🛠 Tech Stack

### 🎨 UI/UX & Creative Design
* **Design Tools:** Figma, Adobe Photoshop, Adobe Illustrator
* **AI Generative Tools:** Midjourney, DALL·E, Stable Diffusion

### 💻 Front-End Web Publishing
* **Core:** HTML5 (Semantic Markup), CSS3 (Flexbox & Grid Layout), JavaScript

## 📁 Core Projects / Web Pages Overview

각 파일은 독립적이고 뚜렷한 테마를 가진 반응형 및 레이아웃 중심의 퍼블리싱 연습 페이지입니다. 사용자 중심의 UI 구조와 시각적 밸런스에 초점을 맞추어 빌드되었습니다.

### 1. 🏡 메인 허브 (Main Index)
* **파일명:** `index.html`
* **주요 특징:** 전체 프로젝트의 입구 역할을 하는 메인 포털 레이아웃입니다. 직관적인 내비게이션(GNB) 구조와 정돈된 UI 섹션 배치를 통해 사용자가 원하는 서브 페이지로 쉽고 빠르게 진입할 수 있도록 설계했습니다.

### 2. 📚 도서 큐레이션 웹 스페이스 (Book Space)
* **파일명:** `book.html`
* **주요 특징:** 다양한 도서 소개 및 큐레이션 레이아웃 콘텐츠입니다. 수많은 도서 데이터와 텍스트 속에서 가독성을 잃지 않도록 여백의 미와 격자(Grid) 구조를 활용하여 시각적 피로도를 낮추는 인포메이션 디자인을 적용했습니다.

### 3. 🎬 영화 미디어 아카이브 (Movie Space)
* **파일명:** `movie.html`
* **주요 특징:** 영화 포스터와 미디어 정보를 시각적으로 강조한 시네마 템플릿입니다. 어두운 배경(Dark Mode) 톤앤매너를 바탕으로 고해상도 이미지 레이아웃을 돋보이게 처리하였으며, 카드 뉴스 형태의 UI 배열을 채택했습니다.

### 4. 🍳 감성 레시피 가이드 (Recipe Space)
* **파일명:** `recipe.html`
* **주요 특징:** 요리 순서와 재료 정보를 일목요연하게 전달해야 하는 기능성 페이지입니다. 단계별 일러스트와 텍스트가 조화롭게 이어지도록 흐름(Flow) 중심의 컴포넌트 디자인을 구현하여 실용성을 극대화했습니다.

### 5. 🐾 반려동물 도감 & 커뮤니티 (Animal Space)
* **파일명:** `animal.html`
* **주요 특징:** 친근하고 부드러운 컬러 톤을 기반으로 설계된 동물 정보 카드 레이아웃입니다. 다양한 생명체의 특징을 카테고리별로 유연하게 분류하고, CSS 요소를 활용해 아기자기하면서도 깔끔한 그리드 배치를 완성했습니다.

---

## 🎯 Key Implementation Features (핵심 퍼블리싱 역량)

* **Semantic Markup:** `header`, `nav`, `main`, `section`, `footer` 등 HTML5 시맨틱 태그를 엄격히 준수하여 검색엔진 최적화(SEO)와 웹 접근성의 기본 틀을 다졌습니다.
* **Modern CSS Layout:** 퍼블리싱 과정에서 불필요한 float 처리를 배제하고, `Flexbox`와 `Grid` 레이아웃 아키텍처를 유연하게 활용하여 화면 구조를 효율적으로 자산화했습니다.
* **Visual Hierarchy:** 폰트 크기, 자간, 그리고 AI 툴로 다듬어진 감각적인 그래픽 오브젝트의 배치를 통해 사용자의 시선 흐름을 자연스럽게 유도하는 디자인 타이포그래피와 레이아웃을 완성했습니다.
